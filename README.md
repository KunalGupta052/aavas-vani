# 🎙️ Aavas Vani

> AI-powered Speech-to-Text and Translation Web Application

Aavas Vani is an AI-based speech recognition and translation platform developed as an internship project. It enables users to upload or record speech, transcribe it into text using OpenAI Whisper, and translate the output into multiple languages.

---

# 📌 Project Overview

The objective of Aavas Vani is to simplify multilingual communication through AI-powered speech recognition.

The application provides:

- Speech-to-Text Conversion
- Multi-language Translation
- Audio Upload
- Live Microphone Support
- Clean and Responsive UI
- Integration with Hugging Face Whisper Models

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/KunalGupta052/aavas-vani.git
```

Move into project directory

```bash
cd aavas-vani
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm start
```

Application will be available at

```
http://localhost:3000
```

---

# 🔑 Environment Variables

Create a `.env` file based on `.env.example`.

Example

```env
HF_TOKEN=YOUR_HUGGINGFACE_TOKEN

NGROK_TOKEN=YOUR_NGROK_TOKEN
```
