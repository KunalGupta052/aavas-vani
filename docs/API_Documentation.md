\# API Documentation



\## Overview



This document describes the APIs used in the Aavas Vani project.



\---



\## External APIs



\### Hugging Face



Purpose:



Speech-to-text processing.



Configuration:



HF\_TOKEN=<YOUR\_TOKEN>



\---



\### ngrok



Purpose:



Expose local backend during development.



Configuration:



NGROK\_AUTHTOKEN=<YOUR\_TOKEN>



\---



\## Internal API



Update this section with backend endpoints.



Example:



POST /transcribe



Input:



Audio File



Output:



Recognized Text
